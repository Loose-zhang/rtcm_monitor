# RTCM Monitor — NTRIP 频点 / 信噪比可视化

接入 NTRIP 数据流（或回放本地 `.rtcm` 文件），实时解码 RTCM3 MSM 观测值，
按卫星 / 信号可视化**频点、载噪比 (CN0)**，并内置**北斗 2026/04 PRN 重构感知校验**，
自动标注每颗 BDS 星属 BDS-2 / BDS-3 并高亮异常。功能定位类似 RTKLIB 的实时监视。

## 功能面板
- **CN0 信噪比柱状图**：每颗星按信号(B1I/B1C/B2a/B2b…)分组着色。
- **卫星 × 信号 矩阵**：行=卫星、列=信号，单元格=CN0（颜色分级），含频点提示。
- **CN0 时间序列**：选定 卫星·信号 后实时累计曲线。
- **天空图 (CN0 雷达)**：按系统环形排布、点大小∝CN0（真实方位/高度角需星历，见下）。
- **频点 / 信号图例**：信号↔频率↔锁定数。
- **北斗重构校验**：
  - C09 / C10 标为 **BDS-2**（B1I/B2I/B3I，正常）；
  - 重构后落在低号位(1–8/11–14)的 **BDS-3** 星若只锁到 B1I，给出“未采集 B1C/B2a/B2b，建议升级接收机固件”告警；
  - BDS-3 星上出现 `7I(B2I)` 判为“B2b 被误标为 legacy B2I”错误。

## 运行
```bash
cd rtcm_monitor
bash run.sh                # 自动装依赖并启动
# 或手动：
pip install -r requirements.txt
python3 app.py
```
浏览器打开 **http://127.0.0.1:7999**

### 接入 NTRIP
在“数据源 → NTRIP 接入”填 Caster 地址 / 端口 / 挂载点 / 用户名 / 密码，点“连接”。
（凭据仅经本机后端转发给 caster，不落盘。需在能访问该 caster 的网络下运行。）

### 接入广播星历流（算位置 / 天空图）
在「广播星历流 (BCEP)」卡片里填第二路 NTRIP（已预填 BKG 多系统广播星历
`ntrip.data.gnss.ga.gov.au:2101/BCEP00BKG0`），点「连接星历」。这一路独立于
观测流，专门接收 1019/1042/1045/1046/1044 等星历报文。接入后：
- 用星历 + 基准站坐标（优先来自观测流的 1005/1006，缺失时自动 SPP）计算每颗观测卫星的 ECEF 位置与方位/高度角；
- 「天空图」自动从「按系统环形近似」切换为**真实极坐标天空图**（中心=天顶，外环=地平，正上=北）。
- 卫星位置算法：GPS/Galileo/BeiDou/QZSS 用标准开普勒广播星历公式，BeiDou GEO 含 -5° 旋转特例；GLONASS 星历仅接收统计、暂不解算位置（当前观测流为北斗，不影响天空图）。

如果筛选后的观测流不含 1005/1006，程序会按单星座使用 MSM
伪距和匹配的广播星历自动做粗略单点定位（SPP）。连续 3 个有效历元稳定后，
该 ECEF 坐标自动作为天空图观察点；页面同时显示所用星座、卫星数、残差 RMS
和历元间离散度。自动坐标用于可视化，不等同于测绘得到的基站坐标；后续若收到
1005/1006，会立即以标准参考站坐标为准。

### 回放本地文件（无需网络，便于演示）
切到“文件回放”，填 `.rtcm` 路径，速度×（5 表示 5 倍速），点“连接”。
例如填入随附的 `Bds.rtcm` 即可复现本项目的分析场景。

## 代码结构
| 文件 | 作用 |
|---|---|
| `app.py` | Flask 后端：状态聚合 + SSE 推送 + 连接 API + 导出 API |
| `ntrip_source.py` | NTRIP 客户端 + 文件回放（独立线程） |
| `rtcm_decode.py` | RTCM3 CRC-24Q 分帧 + MSM 解码（CN0/频点/伪距），支持 GPS/GLO/GAL/BDS/QZSS |
| `freq_table.py` | 各系统 频段→频率/信号名 映射 |
| `bds_recon.py` | 北斗 2026/04 PRN 重构表 + 异常判定规则 |
| `gnss_orbit.py` | 广播星历解码 + 卫星 ECEF 位置(开普勒) + 方位/高度角 |
| `recorder.py` | 录制底座：每 10 分钟保留一个完整历元 + 卫星位置快照，边产生边落盘 |
| `exporter.py` | 第三期导出：按时段合并 RTCM/轨迹、生成轨迹叠加天空图、打包 ZIP |
| `static/index.html` | 单文件仪表盘前端（Chart.js + 原生 SVG） |

## 双通道录制与导出（第三期 / 项 4）
连接基站 / 测站 NTRIP 后即自动录制：按 UTC 整 10 分钟为一个周期，每周期保留
**最后一个完整历元**的原始报文 + 该时刻每颗卫星位置快照，落盘到
`recordings/<sid>/<role>__<挂载点>/`（断电 / 休眠 / 重启后仍可导出）。

在「**录制导出 / 轨迹叠加**」面板里：
- **选时段**：快捷「最近 1h / 6h / 12h / 24h / 全部」，或填绝对起止时间（本地时间）。
- **预览轨迹叠加**：在页面内一张天空图上把时段内所有周期的卫星位置连成轨迹
  （实线 / ● 末点 = 基站，虚线 / ✚ 末点 = 测站，颜色 = 星座）。
- **导出 ZIP + 服务端**：两路通道**按挂载点名分文件夹**，各产出
  `<区间>.rtcm`（合并后可回放）、`<区间>_track.csv`、`<区间>_skyplot.html`
  （自包含轨迹叠加图，浏览器直接打开）。同时写到服务端 `exports/<sid>/<区间>/`
  归档，并打包成 ZIP 由浏览器下载。

- **导入轨迹**：「导入轨迹」按钮可载入离线保存的 `_track.csv` 或整个导出 ZIP，
  无需原始录制即可在叠加图上重新呈现（ZIP 会按内部 `manifest.json` 还原基站 /
  测站样式）。页面内叠加图与导出的 `_skyplot.html` 均支持滚轮缩放 / 拖拽平移 / 复位。

导出 API：`GET /api/recordings`（含可导出范围）、`GET /api/track`、
`POST /api/export`、`GET /api/export_zip`、`POST /api/import_track`。
`recordings/`、`exports/` 均已 gitignore。

## 说明与后续
- 当前流若只含观测(MSM)，**天空图无法给真实方位/高度角**；接入星历报文
  (BDS 1042、GPS 1019、GAL 1045/1046、GLO 1020) 后可在 `static/index.html` 的
  `drawSky()` 中替换为真实极坐标投影（已预留结构）。
- 已支持多系统 MSM4/5/6/7（CN0 取 DF403 或扩展 DF408）。重构校验目前只对北斗启用。
- 北斗系统判定表见 `bds_recon.py`，如官方后续再调整 PRN，可直接改该表。
